# French A1 Adventure

Interactive French beginner revision web page with quizzes, games, and pronunciation audio.

## Files
- `index.html`
- `styles.css`
- `script.js`

## How to run locally
1. Open `index.html` in a browser.
2. Or serve the folder with a simple local server:
   - `python -m http.server 8000`
   - then open `http://localhost:8000`

## GitHub Pages
1. Push the files to GitHub.
2. Open the repository.
3. Go to `Settings` → `Pages`.
4. Select `Deploy from a branch`.
5. Choose `main` and `/root`.
6. Save.

Your site will be available at:
`https://<your-username>.github.io/<your-repo-name>/`

## Features
- French A1 activities
- Alphabet, numbers, days, months
- Greetings and formal/informal practice
- Verb practice for être, avoir, s’appeler
- Quiz cards with answer reveal
- Text-to-speech using browser speech synthesis
- Spin-the-wheel and “Who am I?” games
- Sentence builder challenge
- Final speaking challenge
